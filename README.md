## Explore Geometry in 3D

3D Geometry Lab gives students a visual, interactive way to study geometry in the browser. Rather than relying only on fixed diagrams, it presents shapes, graphs, and spatial relationships that can be examined from different angles.

WebGL rendering and direct controls let you turn scenes, resize objects, and move between views as you learn. The tool can support classroom exercises, independent study, and practical exploration of geometry topics and function behavior.

## Key Capabilities

- View interactive 3D mathematical graphics for geometry learning
- Render scenes directly in the browser with WebGL

- Navigate with mouse-based orbit controls
- Examine eight different geometric solids
- Get AI-assisted support while solving problems
- Display 2D function plots together with 3D content

## Using the Application

Open the interface to inspect solids, change the camera angle, and compare function plots.

A typical session looks like this:

1. Load the application in a modern browser.
2. Select a geometric solid or open a function view.
3. Orbit around the scene with the mouse, or enable hand gestures when available.
4. Use the sliders to modify object size or the current display mode.
5. Turn on wireframe mode to examine the underlying structure.
6. Use the problem-solving tools to support your geometry study.
